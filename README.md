# 🎓 GitTutorial

**GitTutorial** is a practice Android project created while learning **Git** — a starter app built with Android Studio and pushed through real Git workflows as a hands-on exercise. It doubles as a simple login page demo app.

> A sandbox repo to experiment with commits, branches, and version control fundamentals — with a small Android app along for the ride.

---

## 📖 What This Repo Is For

- 🧪 **Git Practice** — Experimenting with the full Git workflow: `init` → `commit` → `status` → `log` → `remote` → `push`.
- 📱 **Android Starter** — A minimal Android application (single `MainActivity` with a simple login page layout) generated by Android Studio, used as the "project under version control" for the tutorial.

## 🛠️ Tech Stack

- **Language:** Java
- **Platform:** Android (Gradle Kotlin DSL build: `build.gradle.kts`)
- **IDE:** Android Studio

## 📂 Project Structure

```
app/src/main/
├── java/com/example/myfirstproject/
│   └── MainActivity.java        # Entry activity
├── res/layout/
│   └── activity_main.xml        # Login page layout
├── res/values/                  # strings, colors, themes
└── AndroidManifest.xml
```

## 🚀 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/ASMmusaffar/GitTutorial.git
   ```
2. Open it in **Android Studio** and wait for the Gradle sync.
3. Run on an emulator or device to see the basic app screen.

## 📚 What I Practiced here

- Creating and pushing an initial commit
- Committing feature changes (login page) step by step
- Managing Git remotes and sync with GitHub
